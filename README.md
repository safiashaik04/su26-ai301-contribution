# Su26 AI301 — Open Source Contributions

This repository documents my open source contributions to [AquaScope](https://github.com/Rekin226/aquascope), a water data aggregation toolkit, as part of CodePath's AI301 AI Open Source Capstone course.

## About AquaScope

AquaScope collects water-related data from sources like USGS, GEMStat, and UN SDG 6, normalizes it into a consistent format, and supports scientific analysis such as flood risk and drought assessment.
