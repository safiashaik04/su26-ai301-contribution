# Su26 AI301 — Open Source Contributions

This repository documents my open source contributions made as part of CodePath's AI301 AI Open Source Capstone course.

## Projects Contributed To

- **[AquaScope](https://github.com/Rekin226/aquascope)** — a water data aggregation toolkit that collects water-related data from sources like USGS, GEMStat, and UN SDG 6, normalizes it into a consistent format, and supports scientific analysis such as flood risk and drought assessment.
- **[job-autofill-extension](https://github.com/ritsth/job-autofill-extension)** — a Chrome extension that autofills job applications (Greenhouse, Lever, Workday) and uses AI to draft answers, cover letters, and resumes from a saved profile.
